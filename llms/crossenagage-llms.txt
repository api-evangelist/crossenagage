# CrossEngage

> CrossEngage is a Berlin-based Customer Data Platform (CDP) and cross-channel marketing platform, backed by Earlybird Venture Capital and now part of Spotler (offered as Spotler Activate Pro). It unifies first-party customer data into 360-degree profiles, builds no-code predictive AI/ML models, manages audience segments, and orchestrates real-time cross-channel campaigns. This llms.txt is generated by the API Evangelist enrichment pipeline from the public catalog and repo artifacts.

## APIs

- [CrossEngage API](https://api.documentation.crossengage.io/): REST API served from https://api.crossengage.io covering User Management (v1.0, v2.0), Product Feed, File Attachments, Export, and Statistics.
